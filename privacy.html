PRIVACY POLICY

隐私政策

生效日期：2026-10-31

本政策适用于“音乐长视频工作台”（Google Cloud 原配置名称为“YouTube 长视频自动运营系统”）及其静态说明网站。应用由创作者本人在自己的电脑上运行，用于管理本人拥有或已获授权管理的频道。

1. 访问哪些数据

应用通过 Google 官方 OAuth 流程请求 YouTube 账号管理权限及 YouTube Analytics 只读权限。Google 授权页会显示具体权限范围。应用不要求提供 Google 密码。

  • 频道身份与统计信息：频道 ID、名称、订阅数及播放等统计。
  • 运营分析：频道与视频的观看、观看时长、订阅增减、平均观看时长、可获得的观众留存、展示和点击率。
  • 发布内容：由所有者提供并确认的视频、封面、标题、简介、标签和发布设置。
  • OAuth 凭据：用于保持已获批准访问的刷新令牌、短期访问令牌及桌面客户端配置。

2. 为什么使用这些数据

用于识别授权频道、生成本机运营报表、分析视频与音乐片段的表现、显示频道增长进度，以及在所有者确认后上传和安排视频发布。应用不出售 Google 用户数据，不将这些数据用于广告画像，也不主动将其用于训练 AI 模型。

3. 本机存储与保护

客户端配置和刷新令牌保存在所有者本机的设置文件中；该文件不进入项目的 Git 版本记录。当前设置文件是本机 JSON 文件，并非加密凭据库。报表和关联记录保存在本机数据库及作品资料中。短期访问令牌可在运行进程中缓存。

所有者负责电脑访问权限、备份与磁盘保护。说明网站不存储这些凭据、频道报表或视频，也不提供上传接口。

4. 数据向哪些服务发送

  • Google / YouTube：授权、令牌兑换、读取数据及确认后的上传请求通过 Google 官方接口完成；配置接口代理时，网络连接会经过所选代理。
  • 所有者配置的 AI 服务：启用并触发 Claude 周报等功能时，应用会把相关频道/视频名称、文本和汇总运营指标发送给 Anthropic / Claude，用于生成所请求的内容；周报也可能随已启用的后台值班执行。Google OAuth 令牌不作为周报内容发送。AI 服务的处理还受其自身条款和账号设置约束，所有者应在使用前确认相关设置。
  • 说明网站托管方：托管服务可能处理访问网站所需的常规网络日志。本说明网站不加入分析脚本、广告、登录表单或追踪 Cookie。

音乐长视频工作台对从 Google API 收到的信息的使用和向其他应用转移该信息，应遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

5. 保留、撤销与删除

本机运营记录与发布资料保留到所有者自行移除。可以在本机工作台的频道页断开授权以删除本机保存的该频道令牌，也可以在 Google 账号的第三方连接页面撤销应用访问权限。撤销授权或删除令牌不会自动删除已经生成的本机报表、备份或已上传视频；这些内容需要所有者另外管理。

如需删除本机频道历史数据及备份，可联系工具所有者，说明需要处理的记录。不得通过电子邮件发送密码、刷新令牌或客户端密钥。

6. 第三方政策与联系

Google 对数据的处理还适用 Google 隐私政策。本工具不是 Google 或 YouTube 官方产品。
